# Решения и история изменений

## Принятые решения

- Общий протокол обслуживается через SerialWorker.
- KivyMD остаётся на ветке 2.x; зависимости фиксируются явно.
- Android использует WiFi как основной канал, USB OTG как резерв.
- Терминал всегда показывает неизвестные строки устройства.

## Последние изменения

- `58bf0ec` — все ответы Android отображаются в терминале.
- `7f4431c` — отмена устаревших polling callback.
- `404197a` — корректный reset транспорта при reconnect.
- `b8d6494` — команды Android приведены к протоколу руководства.
