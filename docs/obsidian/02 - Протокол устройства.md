# Протокол устройства

Команды отправляются строкой с `CRLF`.

## Основные команды

`VER`, `serial`, `SET`, `DEBUG ONLY POS`, `DEBUG ONLY GSM`, `DEBUG ONLY FTG`, `TEST HW`, `TEST ON`, `TEST OFF`, `OUT 1|2|4|8`, `SPK P 0..13`, `LED ALL 1000 500 #`, `RST`.

## Настройки

- `SET GSM_APN <value>`
- `SET GSM_USER <value>`
- `SET GSM_PWD <value>`
- `SET MQTT_URL <host:port>`
- `SET SpkVol <0.0..1.0>`
- `SET REG <4|8>`
- `SET Gps <GNSS|GLONASS>`
- `SET AS` сохраняет настройки в EEPROM.

Ответы могут быть многострочными; неизвестные строки нельзя отбрасывать.
