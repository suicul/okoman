# Сборка и релиз

## Desktop

`python build.py` или workflow Windows. Для Win7 используются Python 3.8.10 и PyInstaller 5.13.2.

## Android

Workflow: `.github/workflows/build-android.yml`. Локально на Linux: `buildozer android debug`. Артефакт — APK в `dist/`.

Важно: сборка требует доступа к GitHub для python-for-android.
