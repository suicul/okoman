# Диагностика

1. Подключить БОД по USB или WiFi.
2. Проверить `VER` и `serial`.
3. Выполнить `TEST HW`; нормальные VIBRO/SPK около 2500.
4. Проверить GPS: `DEBUG ONLY POS`.
5. Проверить GSM/MQTT: `DEBUG ONLY GSM`.
6. Для оптики использовать `TEST ON`, `DEBUG ONLY FOK`, `DEBUG ONLY FTG` и команды `EYES_1`, `FACE_4`, `PHONE5`, `SMOKE6`.

При проблемах сначала смотреть терминал и транспортный лог.
